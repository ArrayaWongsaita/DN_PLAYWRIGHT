# บทที่ 16: ต่อ locator และ filter 🏫

บทนี้เริ่มชุด "locator ขั้นกลาง" และเขียนให้อ่านเองได้ ถ้าติดขัดให้ลองรันตัวอย่างทีละ test แล้วแก้ค่าเล่นดู

## จบบทนี้แล้วทำอะไรได้

- ต่อ locator หลายชั้น เพื่อหา element "ที่อยู่ข้างใน" element อื่น เช่น ปุ่มในการ์ดสินค้าใบใดใบหนึ่ง
- ใช้ `filter` ด้วย `hasText`, `hasNotText`, `has`, `hasNot` เพื่อเลือกเฉพาะใบ/แถวที่ต้องการจากหลายใบที่หน้าตาเหมือนกัน
- หาแถวในตาราง แล้วตรวจหรือกดปุ่มเฉพาะแถวนั้น

## เชื่อมกับที่รู้แล้ว

บท 04 และ 05 ใช้ `page.getByRole(...)` หา element จากทั้งหน้า ปัญหาคือหน้า `/products` มีปุ่ม "เพิ่มลงตะกร้า" 9 ปุ่ม (ปุ่มที่ 10 เป็น "สินค้าหมด") ถ้าเขียน `page.getByRole("button", { name: "เพิ่มลงตะกร้า" }).click()` จะเจอ strict mode violation เหมือนบท 04 บทนี้สอนวิธีบอก Playwright ว่าต้องการปุ่ม "ของการ์ดใบไหน"

## เนื้อหา

### 1. ต่อ locator (chaining)

locator ทุกตัวมี `getByRole`, `getByText`, `getByLabel` ฯลฯ ให้เรียกต่อได้ เหมือนที่เรียกจาก `page` แต่จะค้นหา **เฉพาะข้างใน** element ที่ locator ตัวก่อนหน้าชี้อยู่

```ts
const list = page.getByRole("list", { name: "รายการสินค้า" });
const buttons = list.getByRole("button", { name: "เพิ่มลงตะกร้า" });
```

`list` คือ `<ul aria-label="รายการสินค้า">` และ `buttons` คือปุ่มที่อยู่ในนั้นเท่านั้น ต่อกี่ชั้นก็ได้ และ locator ยังเป็น "คำอธิบายวิธีหา" ที่ยังไม่ได้หาจริง (เหมือนบท 03) จึงเก็บใส่ตัวแปรไว้ใช้ซ้ำได้ ไม่มีค่าใช้จ่ายอะไร

### 2. filter เลือกเฉพาะบางใบ

`getByRole("listitem")` ในหน้า `/products` ได้การ์ดทั้ง 10 ใบ (การ์ดแต่ละใบคือ `<li>`) `.filter(...)` จะตัดใบที่ไม่ต้องการทิ้ง ส่วนที่เหลือยังเป็น locator ต่อได้ตามปกติ

| ตัวเลือก | ความหมาย |
|---|---|
| `hasText: "เมาส์"` | เก็บไว้เฉพาะ element ที่ข้อความข้างใน **มี** คำนี้ (ไม่สนตัวพิมพ์เล็ก/ใหญ่ ตรงบางส่วนก็ได้) |
| `hasNotText: "หนังสือ"` | เก็บไว้เฉพาะ element ที่ข้อความข้างใน **ไม่มี** คำนี้ |
| `has: locator` | เก็บไว้เฉพาะ element ที่ **มี locator นี้อยู่ข้างใน** |
| `hasNot: locator` | เก็บไว้เฉพาะ element ที่ **ไม่มี locator นี้อยู่ข้างใน** |

ตัวอย่างหลัก (ตัวอย่างที่ 1 ในไฟล์ test):

```ts
await page
  .getByRole("listitem")
  .filter({ hasText: "เมาส์ไร้สาย" })
  .getByRole("button", { name: "เพิ่มลงตะกร้า" })
  .click();
```

อ่านจากซ้ายไปขวา: "เอาทุก listitem" แล้ว "เหลือเฉพาะใบที่มีคำว่าเมาส์ไร้สาย" แล้ว "หาปุ่มเพิ่มลงตะกร้าในใบนั้น" แล้ว "คลิก"

### 3. has / hasNot ต้องใช้ locator ที่เริ่มจาก page

ตัวอย่าง: หาการ์ดที่มีปุ่ม "สินค้าหมด" อยู่ข้างใน

```ts
const soldOutCard = page
  .getByRole("listitem")
  .filter({ has: page.getByRole("button", { name: "สินค้าหมด" }) });
```

locator ที่ใส่ใน `has` ต้องเขียนขึ้นต้นด้วย `page.` เสมอ แต่ Playwright จะนำไปหา **ในขอบเขตของ element ที่กำลัง filter** เอง (ทีละการ์ด) ไม่ใช่ทั้งหน้า ผลคือได้การ์ดเดียวคือหมวกแก๊ป

`hasNot` กลับกัน: `filter({ hasNot: page.getByRole("button", { name: "สินค้าหมด" }) })` ได้การ์ดอีก 9 ใบที่ซื้อได้

### 4. filter หลายครั้งและใช้ร่วมกัน

`.filter()` ต่อกันได้ และใส่หลายเงื่อนไขในครั้งเดียวได้ ทุกเงื่อนไขต้องเป็นจริงพร้อมกัน

```ts
const cards = page.getByRole("listitem");
cards.filter({ hasText: "ไร้สาย" }).filter({ hasNotText: "หูฟัง" }); // เมาส์ไร้สาย
cards.filter({ hasText: "ไร้สาย", hasNotText: "หูฟัง" });          // ได้ผลเดียวกัน
```

### 5. แถวในตาราง

`<tr>` คือ role `row` และ `<td>` คือ role `cell` จึงใช้วิธีเดียวกับการ์ดได้เลย หน้า `/admin/products` มีตาราง `aria-label="ตารางสินค้า"` ที่แต่ละแถวมีปุ่ม "ลบ" ของตัวเอง

```ts
const row = page
  .getByRole("table", { name: "ตารางสินค้า" })
  .getByRole("row")
  .filter({ hasText: "คีย์บอร์ดเครื่องกล" });

await expect(row).toContainText("2,490 บาท");
await row.getByRole("button", { name: "ลบ" }).click(); // กดลบเฉพาะแถวนี้
```

`row` ทั้งแถวเป็นข้อความต่อกันของทุกเซลล์ จึงใช้ `toContainText` ตรวจราคาในแถวได้ (บท 05) ถ้าอยากชี้ทีละเซลล์ใช้ `row.getByRole("cell", { name: "..." })`

หน้านี้เปิดได้เฉพาะแอดมิน ตัวอย่างจึง login ผ่านหน้า `/login` ในตัว test ก่อน (บัญชีแอดมิน `admin@dnshop.test` รหัส `admin123`) ซึ่งยาวหน่อย บทหลังๆ จะสอนวิธีไม่ต้อง login ซ้ำทุก test

### เปรียบเทียบ: ทำไมไม่ใช้ nth หรือเลขลำดับ

จะเขียน `getByRole("button", { name: "เพิ่มลงตะกร้า" }).nth(2)` ก็ได้ (บท 17) แต่ถ้าลำดับสินค้าเปลี่ยน test จะกดผิดใบโดยไม่แจ้งเตือน การหาจากข้อความของสินค้า (`hasText`) บอกเจตนาได้ชัดกว่าและไม่พังเมื่อลำดับเปลี่ยน

## จุดที่มักพลาด

- **ใช้ `hasText` กับข้อความสั้นเกินไป**: `hasText: "หนังสือ"` ตรงทั้งหมวดหนังสือและชื่อสินค้าที่มีคำนี้ ถ้าเจอหลายใบให้ใช้ข้อความที่เจาะจงกว่า หรือใส่ regular expression เช่น `hasText: /^เมาส์/`
- **เขียน `has` ด้วย locator ที่ไม่ได้ขึ้นต้นด้วย `page`**: เช่น `has: card.getByRole(...)` จะ error ต้องเป็น `page.getByRole(...)` เสมอ
- **คิดว่า `filter` ต้องมีผลทันที**: filter เป็นแค่การอธิบายวิธีหา ยังไม่ได้ไปหาจริง จึงไม่ต้อง `await` ที่ตัว filter ต้อง `await` เฉพาะตอน `click()` หรือ `expect(...)`
- **ลืมว่า `hasNotText` ไม่ได้บอกว่า element ต้องมีอยู่**: ถ้าไม่มี element ไหนตรงเลย locator จะว่าง และ `toHaveCount(0)` จะผ่าน ระวังเวลาจะตรวจว่า "ไม่มี" ให้แน่ใจว่าหน้าโหลดรายการเสร็จแล้ว (ตรวจจำนวนทั้งหมดก่อน)
- **ใช้ `getByRole("row")` โดยไม่ต่อจากตาราง**: ถ้าหน้ามีหลายตาราง จะได้แถวของทุกตาราง ควรต่อจาก `getByRole("table", { name: "..." })`
- **ใช้ `getByRole("button", { name: "ลบ" })` ตรงๆ ในหน้า admin**: ได้ปุ่มลบทุกแถว (strict mode violation) ต้องต่อจาก row

## หน้าในแอปที่ใช้

**`/products`**
- `<ul aria-label="รายการสินค้า">` การ์ดสินค้า 10 ใบ ชื่ออยู่ใน `<h2>` ที่เป็นลิงก์ ราคาแบบ "590 บาท"
- ทุกใบมีปุ่ม "เพิ่มลงตะกร้า" ยกเว้นหมวกแก๊ป (p05) ที่เป็นปุ่ม disabled "สินค้าหมด"
- เพิ่มลงตะกร้าสำเร็จแสดง `role="status"` ข้อความ `เพิ่ม "{ชื่อสินค้า}" ลงตะกร้าแล้ว` (หน้านี้อาจมี `role="status"` อื่นด้วย เช่นตอนโหลด จึงกรองด้วยข้อความ)

**`/admin/products`** (ต้อง login เป็นแอดมิน)
- `<table aria-label="ตารางสินค้า">` คอลัมน์ ชื่อสินค้า / หมวดหมู่ / ราคา / คงเหลือ / จัดการ
- แถวหมวกแก๊ป: ราคา "350 บาท" คงเหลือ 0
- แถวคีย์บอร์ดเครื่องกล: ราคา "2,490 บาท" คงเหลือ 8

**`/login`**: ช่อง "อีเมล" "รหัสผ่าน" ปุ่ม "เข้าสู่ระบบ" เมื่อสำเร็จจะไปหน้า `/account` (h1 "บัญชีของฉัน")

## แบบฝึกหัดในบทนี้

1. กดเพิ่ม "หนังสือ TypeScript เบื้องต้น" ลงตะกร้าด้วย `hasText` แล้วตรวจข้อความแจ้งผล
2. การ์ด "หมวกแก๊ป" มีปุ่ม "สินค้าหมด" ที่ disabled
3. ใช้ `has` หาการ์ดที่มีปุ่ม "สินค้าหมด" แล้วตรวจว่ามีใบเดียวและเป็นหมวกแก๊ป
4. นับการ์ดด้วย `hasNot` (ได้ 9) และ `hasNotText` (ได้ 7)
5. login เป็นแอดมินแล้วตรวจแถวหมวกแก๊ปในตารางสินค้า
