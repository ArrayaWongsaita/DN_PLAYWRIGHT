# แผนทดสอบ DN Shop: ค้นหา กรอง และโค้ดส่วนลด

ตัวอย่างแผนในรูปแบบที่ planner agent เขียน (Markdown, ชื่อหัวข้อมีเลขลำดับ, มีบรรทัด Seed, ขั้นตอนเป็นข้อๆ, มีผลที่คาดหวัง)
ไฟล์นี้เขียนมือให้ใช้เป็นตัวอย่างอ่านและเป็นข้อมูลให้ generator ในบทที่ 53 ผลจริงของ planner จะได้ชื่อและถ้อยคำต่างจากนี้ และ planner ของ Playwright จะบันทึกแผนไว้ในโฟลเดอร์ `specs/` ของโปรเจกต์ (ไม่ใช่ที่นี่)

สมมติฐาน: ทุกสถานการณ์เริ่มจากแอปที่ยังไม่มีข้อมูลของผู้ใช้ (ตะกร้าว่าง ยังไม่ login) และแต่ละสถานการณ์ทำงานได้เองโดยไม่ต้องพึ่งตัวอื่น

## 1. ค้นหาและกรองสินค้า

**Seed:** `lessons/53-test-agents/seed.spec.ts`

### 1.1 ค้นหาสินค้าที่มีอยู่

**Steps:**
1. เปิดหน้า `/products`
2. พิมพ์ "เมาส์" ในช่อง "ค้นหาสินค้า"
3. กดปุ่ม "ค้นหา"

**Expected Results:**
- เห็นข้อความ "พบสินค้า 1 รายการ"
- เห็นลิงก์สินค้าชื่อ "เมาส์ไร้สาย"

### 1.2 ค้นหาแล้วไม่พบสินค้า

**Steps:**
1. เปิดหน้า `/products`
2. พิมพ์ "ไม่มีสินค้านี้แน่นอน" ในช่อง "ค้นหาสินค้า"
3. กดปุ่ม "ค้นหา"

**Expected Results:**
- เห็นข้อความ "พบสินค้า 0 รายการ"
- เห็นข้อความ "ไม่พบสินค้าที่ค้นหา"

### 1.3 กรองตามหมวดเสื้อผ้า

**Steps:**
1. เปิดหน้า `/products`
2. เลือก "เสื้อผ้า" ใน "หมวดหมู่"

**Expected Results:**
- เห็นข้อความ "พบสินค้า 2 รายการ"
- เห็นลิงก์ "เสื้อยืด DN สีขาว" และ "หมวกแก๊ป"

## 2. ตะกร้าและโค้ดส่วนลด

**Seed:** `lessons/53-test-agents/seed.spec.ts`

### 2.1 เพิ่มสินค้าลงตะกร้า

**Steps:**
1. เปิดหน้า `/products`
2. กด "เพิ่มลงตะกร้า" ที่สินค้า "เมาส์ไร้สาย"

**Expected Results:**
- เห็นข้อความสถานะ `เพิ่ม "เมาส์ไร้สาย" ลงตะกร้าแล้ว`
- ลิงก์ "ตะกร้า (1)" ใน header

### 2.2 ใช้โค้ดส่วนลด DN10

**Steps:**
1. เปิดหน้า `/products` แล้วเพิ่ม "เมาส์ไร้สาย" ลงตะกร้า
2. ไปที่หน้า `/cart`
3. กรอก "DN10" ในช่อง "โค้ดส่วนลด"
4. กดปุ่ม "ใช้โค้ด"

**Expected Results:**
- เห็นข้อความสถานะ "ใช้โค้ด DN10 แล้ว ลด 10%"
- ยอดรวมสินค้า "590 บาท", ส่วนลด "59 บาท", ยอดสุทธิ "531 บาท"
