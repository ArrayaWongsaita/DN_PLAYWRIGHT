# บทที่ 10: อัด test ด้วย codegen แล้วเกลาให้ดี 🏫

## จบบทนี้แล้วทำอะไรได้

- เปิด codegen เพื่ออัดการใช้งานเว็บเป็นโค้ด test
- ใช้ปุ่ม assert ของ codegen เพื่อเพิ่มการตรวจผล
- เกลาโค้ดที่อัดได้: เปลี่ยนเป็น `getByRole`, ตัดบรรทัดเกิน, ใส่ `expect` และใช้ URL แบบสั้น

## เชื่อมกับที่รู้แล้ว

บท 01-09 เราเขียนโค้ดเองทีละบรรทัด ทั้งหา element ด้วย locator (บท 04-05) และสั่ง action (บท 06-09) บทนี้ให้ **เครื่องมือเขียนให้ก่อน** แล้วเรามาตรวจและแก้ ทักษะที่ใช้คือการอ่านโค้ดว่า locator นี้ดีหรือยัง และ test นี้ตรวจอะไรจริงๆ

## เนื้อหา

### codegen คืออะไร

`codegen` คือเครื่องมือของ Playwright ที่เปิด browser ให้เราใช้งานเว็บตามปกติ (คลิก พิมพ์ เลือก) ขณะเดียวกันก็เขียนโค้ด Playwright ให้เรียลไทม์ในหน้าต่าง **Playwright Inspector** เหมาะกับการได้ "ร่างแรก" ของ test หรือการหาว่า element หนึ่งๆ ควรใช้ locator อะไร

### ต้องเปิด 2 terminal

codegen ต้องการให้แอปรันอยู่ จึงต้องมี 2 terminal พร้อมกัน

**Terminal ที่ 1: รันแอป** (เปิดทิ้งไว้ ห้ามปิด)

macOS (Terminal) และ Windows (PowerShell):

```bash
pnpm app
```

รอจนเห็นว่าแอปพร้อมแล้ว (ครั้งแรกจะ build ก่อน ใช้เวลาสักครู่) แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3100 ถ้าเห็นหน้า DN Shop ก็พร้อม

**Terminal ที่ 2: เปิด codegen**

- **macOS**: เปิดแท็บใหม่ใน Terminal ด้วย `Command + T` แล้ว `cd` ไปยังโฟลเดอร์โปรเจกต์
- **Windows**: เปิด PowerShell หน้าต่างที่สอง (หรือกด `Ctrl + Shift + T` ใน Windows Terminal) แล้ว `cd` ไปยังโฟลเดอร์โปรเจกต์

จากนั้นรัน:

```bash
pnpm codegen
```

คำสั่งนี้ตั้งไว้ใน `package.json` ให้เปิดที่ `http://localhost:3100` อยู่แล้ว จะมีสองหน้าต่างเปิดขึ้น:

1. **หน้าต่าง browser**: ใช้งานเว็บตามปกติ ทุกการกระทำจะถูกอัด
2. **หน้าต่าง Playwright Inspector**: แสดงโค้ดที่อัดได้ มีปุ่ม Copy และปุ่ม Record (จุดแดง) เริ่ม/หยุดอัด

ถ้าเปิดไม่ขึ้นหรือขึ้น error `ECONNREFUSED` แสดงว่าแอปใน terminal ที่ 1 ยังไม่ทำงาน

เมื่อเสร็จ ปิดหน้าต่าง browser แล้วกด `Ctrl + C` ใน terminal ทั้งสองเพื่อหยุด (ทั้ง Mac และ Windows)

### เครื่องมือบนแถบของ codegen

บนแถบเล็กๆ ของหน้าต่าง browser มีปุ่มสำคัญ:

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| Record | เริ่ม/หยุดอัด (ถ้าหยุดไว้ การกดจะไม่ถูกอัด) |
| Pick locator | ชี้ element แล้วดูว่า locator ที่แนะนำคืออะไร (ไม่เพิ่มบรรทัดในโค้ด) |
| Assert visibility | คลิก element แล้วได้ `expect(...).toBeVisible()` |
| Assert text | คลิก element แล้วได้ `expect(...).toContainText(...)` |
| Assert value | คลิกช่องกรอกแล้วได้ `expect(...).toHaveValue(...)` |

(ชื่อปุ่มอาจต่างกันเล็กน้อยตาม Playwright เวอร์ชัน เอาเมาส์ไปชี้จะเห็นคำอธิบาย) ถ้า Inspector มีตัวเลือกภาษา ให้เลือกแบบ **Playwright Test (TypeScript)** โค้ดที่ได้จะมีรูปร่าง `test("test", async ({ page }) => { ... })`

### โค้ดที่อัดได้ต้องเกลาเสมอ

codegen เก่งเรื่องจับ "สิ่งที่กด" แต่ไม่รู้ว่าเรา **อยากตรวจอะไร** ข้อบกพร่องที่พบบ่อยของโค้ดดิบ:

| ปัญหาในโค้ดดิบ | วิธีเกลา |
|---|---|
| ไม่มี `expect` เลย (test ไม่ได้ตรวจอะไร) | เพิ่ม `expect` หลังขั้นสำคัญ หรือใช้ปุ่ม assert ตอนอัด |
| `goto("http://localhost:3100/...")` | เปลี่ยนเป็น `goto("/...")` (baseURL อยู่ใน config แล้ว) |
| `click()` ซ้ำก่อน `fill()` | ลบ `click()` ออก เพราะ `fill` ทำให้เองอยู่แล้ว |
| `getByText(...)` / `getByPlaceholder(...)` ทั้งที่มี role ที่ดีกว่า | เปลี่ยนเป็น `getByRole(...)` (บท 04) |
| ใช้ locator ยาว เช่น `.locator('div').filter(...)` | หา role หรือ label ที่ตรงกว่า |
| เรียก locator ตัวเดิมซ้ำหลายบรรทัด | เก็บใส่ตัวแปร เช่น `const searchBox = ...` |
| ใช้ `.first()`/`.nth()` ทั้งที่ระบุให้ชัดได้ | ระบุจากชื่อหรือ landmark ให้ชัด |

ตัวอย่างในไฟล์ `codegen.spec.ts` มีทั้ง **"โค้ดดิบจาก codegen"** และ **"โค้ดหลังเกลา"** ของเรื่องเดียวกัน ให้เปรียบเทียบทีละบรรทัด ทั้งสองผ่านทั้งคู่ แต่ตัวแรกไม่ได้ตรวจว่าสำเร็จจริง

> หมายเหตุ: โค้ดที่ codegen ให้อาจต่างจากในตัวอย่างเล็กน้อยตามเวอร์ชันและตามจังหวะที่คุณกด (เช่นใช้ `'` เดี่ยวแทน `"` คู่) เป็นเรื่องปกติ หลักการเกลายังเหมือนกัน

## จุดที่มักพลาด

- **ลืมรันแอปก่อน**: `pnpm codegen` ต้องการ `pnpm app` ใน terminal อื่นที่ยังทำงานอยู่
- **เชื่อโค้ดที่อัดโดยไม่อ่าน**: โค้ดผ่านไม่ได้แปลว่าตรวจถูก (test ที่ไม่มี `expect` ผ่านเสมอ)
- **วางโค้ดทั้งก้อนที่รวม `import`**: ไฟล์นี้มี `import` อยู่แล้ว ให้วางเฉพาะเนื้อใน `test(...)` เข้าไปใน `test.fixme` ของข้อนั้น
- **ลืมเปลี่ยน `test.fixme` เป็น `test`**: ถ้ายังเป็น `fixme` test จะถูกข้าม
- **อัดยาวเกินไป**: อัดทีละเรื่องสั้นๆ (5-10 การกด) ถ้ายาวมากจะเกลาและหาที่พังยาก
- **hover หรือเลื่อนเมาส์ไปโดนอะไรที่ไม่ตั้งใจ**: codegen อัดเฉพาะการคลิก/พิมพ์/เลือก ถ้ามีบรรทัดแปลกๆ ให้ลบทิ้ง

## หน้าในแอปที่ใช้

- **`/products`**: ช่องค้นหา, select "หมวดหมู่" (ทั้งหมด, อุปกรณ์ไอที, เสื้อผ้า, ของใช้ในบ้าน, หนังสือ), ข้อความ "พบสินค้า N รายการ"
- **`/products/p04`** (เสื้อยืด DN สีขาว): ปุ่ม "เพิ่มจำนวน", ช่อง "จำนวน", ปุ่ม "เพิ่มลงตะกร้า"
- **`/register`**: กดปุ่ม "สมัครสมาชิก" โดยไม่กรอกอะไรจะแสดงข้อความ error ใต้ช่อง เช่น "กรุณากรอกชื่อ" และ "กรุณายอมรับเงื่อนไขการใช้งาน"

## วิธีรันบทนี้

ส่วนที่ต้องเปิด codegen ทำตามหัวข้อ "ต้องเปิด 2 terminal" ข้างบน ส่วนการรัน test ที่เขียนเสร็จแล้ว:

```bash
pnpm test 10-codegen
```

ผลที่ควรได้ก่อนเริ่มทำแบบฝึกหัด: `2 passed` และ `3 skipped` (ตัวอย่างสองข้อ คือ "โค้ดดิบ" กับ "โค้ดหลังเกลา")

## แบบฝึกหัดในบทนี้

แต่ละข้อทำตามนี้: เปิด codegen → อัดตามขั้นตอนที่ระบุในไฟล์ → copy โค้ดมาวางใน `test.fixme` ของข้อนั้น → เกลา → เปลี่ยนเป็น `test` → รันให้ผ่าน

1. อัดการเลือกหมวดหมู่ "หนังสือ" แล้วเกลาให้ตรวจ "พบสินค้า 3 รายการ" และเห็นหนังสือ Playwright
2. อัดการเพิ่มจำนวนเสื้อยืด 2 ครั้งแล้วเพิ่มลงตะกร้า แล้วเกลาให้ตรวจจำนวนในช่อง ข้อความยืนยัน และจำนวนที่ลิงก์ตะกร้า
3. อัดการกดสมัครสมาชิกโดยไม่กรอกข้อมูล แล้วเกลาให้ตรวจข้อความ error
