# Prompt สำหรับให้ AI สำรวจ DN Shop (บทที่ 52)

copy ข้อความในกรอบไปวางใน Claude Code ได้เลย (เปิดแอปไว้ที่ http://localhost:3100 ก่อน ดูวิธีใน README.md)
ถ้าคุณเปลี่ยนไปใช้ AI ตัวอื่น prompt ยังใช้ได้ เพราะเป็นแค่ข้อความ ส่วนวิธีเชื่อม Playwright ให้ดูเอกสารของเครื่องมือนั้น

## ข้อ A: สำรวจหน้า /products (ใช้กับแบบฝึกหัดข้อ 1)

```text
ใช้ Playwright MCP เปิด http://localhost:3100/products แล้วสำรวจหน้านี้:
1. บอกว่ามี element ที่โต้ตอบได้อะไรบ้าง (ชื่อและ role)
2. ลองเลือก "เรียงตาม" เป็น "ราคาต่ำไปสูง" แล้วบอกว่าสินค้าตัวแรกในรายการคืออะไร
จากนั้นเขียน Playwright test ภาษา TypeScript หนึ่งข้อจากสิ่งที่เห็นจริง โดยทำตามกติกา:
- ใช้ getByRole / getByLabel เท่านั้น ห้าม CSS selector และ XPath
- ห้าม waitForTimeout ใช้ expect(locator).toBeVisible() หรือ assertion ตัวอื่นที่รอเอง
- ห้ามใช้ expect(await locator.isVisible()).toBe(true)
- test ต้องทำงานได้คนเดียว ไม่พึ่ง test ตัวอื่น และจบด้วย assertion ที่ตรวจผลลัพธ์จริง
- baseURL ตั้งไว้แล้ว ใช้ page.goto("/products")
```

## ข้อ B: สำรวจตะกร้าและโค้ดส่วนลด (ใช้กับแบบฝึกหัดข้อ 2 และ 3)

```text
ใช้ Playwright MCP เปิด http://localhost:3100/products แล้วทำตามนี้ทีละขั้น:
1. กด "เพิ่มลงตะกร้า" ที่สินค้า "เมาส์ไร้สาย" แล้วรอจนเห็นข้อความว่าเพิ่มแล้ว
2. ไปที่ /cart กรอกโค้ดส่วนลด DN10 แล้วกด "ใช้โค้ด"
3. บอกค่าที่เห็นของยอดรวมสินค้า ส่วนลด และยอดสุทธิ
4. ลองอีกครั้งด้วยโค้ดที่ไม่มีอยู่จริง แล้วบอกข้อความที่ขึ้น
จากนั้นเขียน Playwright test (TypeScript) หนึ่งข้อต่อหนึ่งสถานการณ์ ตามกติกาเดียวกับข้อ A
ข้อสำคัญ: ในหน้านี้มี element role="alert" ว่างๆ อยู่ด้วย ให้กรองด้วย filter({ hasText }) ก่อนตรวจข้อความ
```

## ข้อ C: ให้ AI ตรวจ test ของตัวเอง (ทำหลังได้ test จากข้อ A หรือ B)

```text
ตรวจ test ที่คุณเพิ่งเขียนตามรายการนี้ และแก้ไขถ้าพบ:
1. มี CSS selector, XPath หรือ page.$ ไหม
2. มี waitForTimeout ไหม
3. มี expect(await ...).toBe(...) แทน expect(locator).toBeXxx() ไหม
4. ทุก test จบด้วย assertion ที่ตรวจผลลัพธ์จริงไหม
5. test พึ่งลำดับหรือข้อมูลจาก test อื่นไหม
แล้วรันด้วย pnpm test 52-mcp-cli --repeat-each=5 ถ้ามี test ที่ผ่านบ้างล้มบ้าง ให้บอกสาเหตุ
```

## ข้อ D: ถามเฉพาะโครงสร้างหน้า (ไม่ให้เขียน test)

```text
ใช้ Playwright MCP เปิด http://localhost:3100/login แล้วสรุปเป็นตารางว่าหน้านี้มี textbox ปุ่ม และลิงก์อะไรบ้าง
พร้อมชื่อที่ใช้กับ getByRole ยังไม่ต้องเขียน test
```

ทุกครั้งที่ AI ตอบ ให้ตรวจสิ่งที่มันเขียนเทียบกับหน้าจริงเสมอ (อย่าเชื่อชื่อปุ่มที่ AI "จำได้" ถ้ามันไม่ได้เปิดหน้าจริง)
